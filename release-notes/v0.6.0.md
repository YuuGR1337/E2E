# v0.6.0 — find the breaking commit, audit flaky test code, fixes on pull requests

This release adds two tools no other testing MCP server offers (checked October
2026), closes the gaps found in a comparison with the most-starred testing MCPs,
and hardens the hosted endpoint. Everything still runs locally, free and MIT
licensed.

## New

- **`bisect-failure`** (tool 16). Binary-searches git history for the commit
  where a test started failing. Each step runs the test in a temporary
  `git worktree` with your installed `node_modules` linked in, so your
  checkout, branch and uncommitted changes are untouched. It first confirms the
  test passes at `good` and fails at `bad`, skips commits it cannot test (as
  `git bisect skip` does), and reports the first bad commit with its author,
  changed files and the failure there. `good` defaults to the newest commit
  where the run history saw the test pass; `repeat` handles intermittent
  failures.
- **`audit-tests`** (tool 15). Scans the test code for flake risks: hard waits,
  `setTimeout` sleeps, one-shot assertions (`expect(await x.isVisible()).toBe(true)`
  and similar), missing `await`, `.only`, `force: true`, `networkidle`, element
  handles, layout and hashed-class selectors, `timeout: 0`, hard-coded localhost
  URLs and serial mode. Files are ranked by their findings weighted by their
  tests' flaky rate in the history. `fix: true` rewrites the mechanical cases
  (web-first assertions, adding `await`, removing `.only`), re-runs the touched
  files and restores them if the run fails.
- **One-click fixes on pull requests.** `ci --verify-fixes` proves each
  `suggest-fix` proposal in CI; `--review` posts the verified ones as GitHub
  suggested changes, only on lines in the PR diff and never twice. The Action
  gains `review` and `verify-fixes` inputs (it needs `pull-requests: write` to
  post).
- **`doctor` command.** `npx playwright-e2e-mcp doctor` checks Node, the
  Playwright config, the Playwright install and its browsers, test files, MCP
  client configs and the agent skill; `--json` for scripts.
- **Structured results.** Every tool returns `structuredContent` (`ok`, and
  `error` on failure) next to its Markdown; the ten tools agents chain declare
  an `outputSchema`. `PW_MCP_OUTPUT_SCHEMAS=0` leaves the schemas out of
  tools/list.
- **`device` and `channel` for every page tool.** Playwright device presets
  (`iPhone 15`, `Pixel 7`, `iPad Pro 11`…) and the installed Chrome or Edge
  (`chrome`, `chrome-beta`, `msedge`, `msedge-beta`).
- **Docker image on GHCR.** Each release tag builds, smoke-tests and pushes
  `ghcr.io/xsignon-secure/playwright-e2e-mcp`.

## Security

- The hosted endpoint counts wrong bearer tokens and wrong access keys per
  client and answers `429` past `PW_MCP_MAX_FAILED_AUTH` (default 20 per 15
  minutes). Forwarded-for headers are trusted only on Vercel or with
  `PW_MCP_TRUST_PROXY=1`.
- `PW_MCP_OAUTH_REDIRECT_HOSTS` optionally limits which hosts OAuth clients may
  return users to.
- Tokens shorter than 32 characters log a warning.

## Changed

- **Node 22 or newer is required** (Node 20 reached end of life in April 2026).
  The Docker image is on Playwright 1.64.1, and the MCP SDK on 2.4.
- Sixteen tools; all definitions cost about 12k tokens of context, the `core`
  profile about 4k (unchanged). The `triage` profile adds `audit-tests` and
  `bisect-failure`.
- `npm run coverage` reports unit-test coverage.
- No new runtime dependencies.
