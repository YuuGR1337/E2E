# v0.3.1 — any AI agent can install it

### One command: `init`

```bash
npx -y playwright-e2e-mcp init
```

Run from a project root, it finds the clients the project uses (Claude Code,
Cursor, VS Code, Gemini CLI, Codex) and merges a `playwright-e2e` server entry
into each one's project config, keeping every other server and setting. It also
copies the agent skill into `.agents/skills/` and, for Claude Code,
`.claude/skills/`. Running it again changes nothing; a config that isn't valid
JSON is reported and left untouched. `--client all|cursor,vscode…`,
`--tools=core`, `--no-skill` and `--dry-run` are available, and `windsurf`
writes its user-level config. The npm package now ships the skill for this.

### Install guide written for agents

`llms-install.md` walks an agent through prerequisites, install and a check
that the tools answer. Point any coding agent at it:

> Install the playwright-e2e-mcp server and skill by following
> https://raw.githubusercontent.com/xsignon-secure/E2E/main/llms-install.md

`llms.txt` indexes the install routes and docs for agents that look for it.

### Native installers

- **Claude Code plugin** (server + skill): `/plugin marketplace add xsignon-secure/E2E`,
  then `/plugin install playwright-e2e-mcp@xsignon-secure`.
- **Gemini CLI extension**: `gemini extensions install https://github.com/xsignon-secure/E2E`.
- **Skill only, any agent**: `npx skills add xsignon-secure/E2E`.

The README also gets one-click install buttons for Cursor, VS Code and Claude
Desktop.
