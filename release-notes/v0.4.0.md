# v0.4.0 — accessibility audits, test-order diagnosis, root-cause grouping

This release adds what a market review of E2E testing MCP servers and agent
skills showed was still missing: accessibility checks that work behind a login,
a way to catch tests that depend on test order, failures grouped by cause, and
a skill that teaches how to write tests, not only how to call the tools.

## New

- **`audit-accessibility`** (tool 12). Runs axe-core against WCAG 2.2 A/AA (or
  `wcag2a` … `best-practice`, `all`) on any page. It takes the same
  `storageState`, `headers` and `actions` as `inspect-page`, so signed-in pages
  and open dialogs can be audited. Violations come back worst first, with WCAG
  criteria, a help link and the offending elements as verified Playwright
  locators, and the result ends with an `@axe-core/playwright` check to paste
  into the spec. axe-core is bundled and evaluated in the page, so a
  Content-Security-Policy does not block it. It is part of the `inspect` profile.
- **`diagnose-flaky` `order: true`** (Playwright 1.64+). Runs the target spec
  files in random orders with one worker (`--shuffle`, `--fully-parallel`),
  replays a failing order, and reads each test as order dependent, flaky
  regardless of order, or failing in every order. For an order-dependent test
  it names the test it relies on or is broken by, and prints the
  `--shuffle=<seed>` command that reproduces it. `PW_MCP_SHUFFLE_SEEDS` replays
  given orders.
- **Root-cause grouping in `run-test`.** Failures with the same kind and first
  error line are shown once, with the other tests listed under them, and the
  result opens with the number of distinct causes. `get-failure` indexes are
  unchanged. The `ci` command and the GitHub Action report inherit it.
- **Skill: `references/writing-tests.md`.** Locators, web-first waiting,
  signing in with a setup project, data isolation, network and clock mocking,
  structure, config, a flake-pattern table and a review checklist. SKILL.md now
  covers accessibility audits and test-order diagnosis.

## Changed

- Twelve tools; all definitions cost about 5.5k tokens of context, the `core`
  profile about 2.2k.
- New runtime dependency: `axe-core` (MPL-2.0), about 0.7 MB added to the
  `.mcpb` bundle.
