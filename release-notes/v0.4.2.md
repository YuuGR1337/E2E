# v0.4.2 — claude.ai sign-in, clearer hosted endpoint, free and open source

- **claude.ai connectors can sign in.** A token-protected HTTP bridge is now
  also a small OAuth 2.1 server (discovery, dynamic client registration,
  authorization code with PKCE, refresh tokens), so claude.ai custom
  connectors connect by typing the access key on a sign-in page. It keeps no
  state; changing `PW_MCP_HTTP_TOKEN` signs every client out. The plain bearer
  token still works.
- **Clearer hosted endpoint.** On a serverless deployment, which has no
  browser, browser tools now say so and point to the local install instead of
  suggesting an install that cannot work there, and `audit-accessibility` no
  longer fails to find axe-core.
- **`init --client`** accepts the flag more than once
  (`--client gemini --client codex`), as well as a comma separated list.
- **Free and open source, stated plainly** in the README: MIT, no account or
  API key, no telemetry, free dependencies, and a Deploy with Vercel button
  to host your own bridge.
