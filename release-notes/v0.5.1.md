# v0.5.1 — page tools on the hosted endpoint, a shorter README

- **The hosted endpoint opens pages.** The Vercel bridge now bundles a
  Chromium build for serverless functions, so with the token
  `inspect-page`, `validate-selector`, `audit-accessibility` and
  `audit-performance` work on public URLs from ChatGPT, claude.ai and other
  remote clients. The private-address guard still applies, Firefox and WebKit
  are refused there, and running your own tests still needs the local install.
  `PW_MCP_SERVERLESS_CHROMIUM=0` turns it off.
- **A README you can read on one screen.** Badges, key features, a standard
  config with setup for each client, and a first prompt to try. The full tool
  reference, the hosted endpoint guide and the development notes moved to
  `docs/`, and the security model to `SECURITY.md`.
- **Clearer hosted messages and landing page.** A test run on the hosted
  endpoint now says it has no copy of your project (not that it has no
  browser), and the landing page separates what works there from what needs
  the local install, with a live status check and Windows commands.
- **npm description** shortened to fit npm's 255-character limit, so it no
  longer stops mid-sentence.
