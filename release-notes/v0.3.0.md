# v0.3.0 — per-test flaky verdicts, a CI command and lighter tool lists

### Flaky diagnosis that names the cause

`diagnose-flaky` now repeats the tests in **one Playwright process**
(`--repeat-each`) instead of one process per run, so the browser and workers
start once. On the integration fixture five repetitions of two tests took about
6 s instead of 7.5 s; suites with expensive setup save more. A small extra
reporter records every attempt, because Playwright's JSON report keeps only one
result per test.

The verdict is now **per test**: passes, failures, duration spread and first
error for each test, instead of one verdict for the whole run.

`isolate: true` adds a second pass. The tests are repeated fully parallel, then
the failing ones are repeated with one worker, and each is read as:

- **fails only in parallel**: shared state between tests (same account, DB rows,
  files, ports). The fix is data isolation, not retries.
- **flaky even alone**: a race inside the test or the app.
- **fails alone too**: a real bug.

`separateProcesses: true` keeps the old one-process-per-run behaviour for flakes
that depend on global setup or a cold start. Each repetition is still recorded
as its own run in the history, so `analyze-history` reads it as before.

### CI without an agent

`npx -y playwright-e2e-mcp ci` runs the suite and writes one Markdown report
(run summary, `suggest-fix` diffs, flaky verdicts) to stdout, `--output` and the
GitHub job summary. Exit code 0 passed, 1 tests failed, 2 the run failed.

The repository is now also a GitHub Action, `uses: xsignon-secure/E2E@v0.3.0`,
which keeps one PR comment up to date when the run fails.

### Smaller tool lists

`--tools=` (or `PW_MCP_TOOLS`) picks which tools the server exposes, by name or
profile: `core`, `triage`, `inspect`, `author`. All eleven tool definitions cost
about 5.2k tokens of context on every request; `core` (run, status, failure,
fix, flaky, list) costs about 2.4k.

### Docker

A `Dockerfile` based on the Playwright 1.63 image runs the stdio server or the
`ci` command against a project mounted at `/work`. CI builds it and completes an
MCP handshake inside it.

### New home: xsignon-secure/E2E

The project now lives at https://github.com/xsignon-secure/E2E. Releases publish
to the MCP Registry as **`io.github.xsignon-secure/E2E`**. The registry only
grants a namespace to the GitHub owner that publishes it. The old
`io.github.trajectiq-ai/E2E` entry stays at 0.2.2. The npm package name,
`playwright-e2e-mcp`, does not change.

### Upgrading

Nothing to change. `diagnose-flaky`'s response layout changed (a per-test table
replaces the per-run table, unless `separateProcesses` is set); anything parsing
that Markdown should read the new table. The agent skill is updated to 0.3.0.
